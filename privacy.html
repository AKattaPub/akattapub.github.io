Privacy Policy

AKattaPub Uploader · last updated 28 October 2026

Who uses this app

AKattaPub Uploader is a private tool run on a single personal computer by the owner of the AKattaPub accounts (contact: akattapub@gmail.com). It only connects to accounts owned by AKattaPub and is not offered to anyone else.

What data it accesses

With the owner's consent through Google sign-in, the app uses the YouTube Data API and the YouTube Analytics API to: upload AKattaPub's own videos with their titles, descriptions and tags; change the visibility of those videos (private or public); post a comment on those videos; read the channels' basic information and statistics. It works the same way with AKattaPub's own Instagram, TikTok (through Buffer) and X accounts, to publish AKattaPub's own videos.

How data is stored

Access tokens are stored only on the owner's computer. Channel data and statistics are used only by the owner to publish videos and to understand how they perform. No data is sold, shared with third parties or used for advertising, and no personal data of viewers or other users is collected.

Google user data

AKattaPub Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services: see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time from Google account permissions (and from the security settings of the other platforms). Revoking access and deleting the local token files removes all data held by the app. For any request, write to akattapub@gmail.com.

Chi usa questa app

AKattaPub Uploader è uno strumento privato che gira su un solo computer personale, usato dal titolare degli account AKattaPub (contatto: akattapub@gmail.com). Si collega solo ad account di AKattaPub e non è offerto ad altri.

A quali dati accede

Con il consenso del titolare, dato con l'accesso a Google, l'app usa la YouTube Data API e la YouTube Analytics API per: caricare i video di AKattaPub con titoli, descrizioni e tag; cambiarne la visibilità (privato o pubblico); scrivere un commento sotto quei video; leggere le informazioni e le statistiche dei canali. Allo stesso modo pubblica i video di AKattaPub sui suoi account Instagram, TikTok (tramite Buffer) e X.

Come sono conservati

I token di accesso restano solo sul computer del titolare. I dati e le statistiche dei canali servono solo al titolare per pubblicare i video e capire come vanno. Nessun dato viene venduto, condiviso con terzi o usato per la pubblicità, e non si raccolgono dati personali degli spettatori o di altri utenti.

Dati degli utenti Google

L'uso e il trasferimento delle informazioni ricevute dalle API di Google da parte di AKattaPub Uploader rispettano le norme sui dati utente dei servizi API di Google, compresi i requisiti di uso limitato. L'app usa i servizi API di YouTube: vedi i Termini di servizio di YouTube e le Norme sulla privacy di Google.

Revoca dell'accesso e cancellazione

L'accesso si revoca in qualsiasi momento dalle autorizzazioni dell'account Google (e dalle impostazioni di sicurezza delle altre piattaforme). Revocando l'accesso e cancellando i file dei token sul computer si eliminano tutti i dati dell'app. Per qualsiasi richiesta scrivi a akattapub@gmail.com.
